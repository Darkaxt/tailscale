# Windows tray icon provenance

These four multi-resolution ICO groups are the unmodified connected,
disconnected, exit-node-online and exit-node-offline resources from the
official Tailscale Windows GUI client `1.103.307`. The source executable was
the preserved `tailscale-ipn.exe` with SHA-256
`5cb12834487a18c7356995be33aa12ed59d9f533b9dc134069c0dca42d44b133`.

The resources remain copyright Tailscale Inc. and Contributors and are used
only to represent Tailscale connection state in this compatible client. The
TailDNS product name, menu and release identity remain independent.

Resource-group mapping:

- `connected.ico`: group 8
- `disconnected.ico`: group 10
- `exit-node-online.ico`: group 15
- `exit-node-offline.ico`: group 16
